# 讲清楚

> 把刚学会的，讲成别人听得懂的。

![讲清楚演说训练](public/og.png)

**讲清楚**是一款面向中文表达训练的本地优先 PWA。它把一次练习组织成完整闭环：限时阅读材料、面向指定听众演说、获得可核对的反馈，再围绕同一题目重讲并比较变化。

项目既可以只使用浏览器内的本地量表，也支持由使用者自带 API Key（BYOK）获取更深入的 AI 反馈。原始录音不会发送给 AI 服务商。

## 为什么做这个项目

很多表达工具停在“给一份分数”或“润色一段文字”。讲清楚更关心下一遍能否真的讲得更好，因此把训练设计成四个连续步骤：

1. **限时准备**：阅读有明确取舍的题目和资料，记下提纲。
2. **开口表达**：录制一段面向特定听众、具有时间限制的演说。
3. **获得反馈**：结合讲稿、时长和本机声音指标，给出可执行的改进动作。
4. **同题重讲**：立即再讲一遍，只比较两次都能可靠观察的维度。

## 已有功能

- 内置教育、职场、公共服务、产品伦理等多类中文演说题目。
- 支持导入自己的题目、听众、任务和训练资料。
- 可选公开资料研究：生成带来源引用的训练题，并标记资料状态。
- 使用浏览器 `MediaRecorder` 完成录音、暂停、回听和重录。
- 在 Web Worker 中运行 Whisper：优先使用 WebGPU，不支持时回退到 WASM。
- 在本机分析有效发声时长、停顿、音量动态、削波、音高和发音段速度。
- 提供内容、结构、论据、清晰度、口头表达和时间控制六维本地量表。
- 支持 DeepSeek、Anthropic、OpenAI 兼容及 Anthropic 兼容服务的 BYOK 深度反馈。
- 对 AI 返回结果做结构校验，并核对讲稿引文、声音时间段、指标和资料来源证据。
- 保存训练历史、前后两遍对比和最近训练趋势。
- 支持导出训练记录、删除单次记录或清空本地数据。
- 提供安装清单与 Service Worker，可作为 PWA 使用。

## 隐私与安全边界

讲清楚采用本地优先设计，但“本地优先”不等于所有功能都完全离线：

| 数据 | 默认去向 | 说明 |
| --- | --- | --- |
| 原始录音 | 当前设备 | 只有开启保存选项后才写入 IndexedDB；不会上传给 AI 服务商。 |
| 转写与声音分析 | 当前设备 | Whisper 和声音分析在浏览器内运行；首次使用需从 Hugging Face 下载模型。 |
| 训练历史与生成题目 | 当前设备 | 保存在 `localStorage`；录音与文字记录分开存储。 |
| AI 服务 API Key | 页面内存 | 可选保留到当前标签页会话；不会写入训练历史或导出文件。 |
| AI 深度反馈数据 | 所选服务商 | 仅在使用者明确同意后发送讲稿、题目资料和聚合声音指标，不发送原始录音。 |
| 公开资料研究 | 部署方配置的 Anthropic 服务 | 只发送研究议题，不使用使用者在 AI 反馈页填写的 Key。 |

BYOK 请求通过本站同源服务端转发。转发层要求同源 JSON 请求，只允许 HTTPS 公网域名，拦截内网/IP 地址、重定向和未授权请求头，并对响应禁用缓存。使用第三方中转站时，中转站仍然能够读取 API Key 和被授权发送的内容，请只连接可信服务。

## 本地运行

### 环境要求

- Node.js `>= 22.13.0`
- npm
- 推荐使用新版 Chrome 或 Edge，以获得 WebGPU 和更完整的录音体验；其他现代浏览器可以回退到 WASM 或手动讲稿。

### 启动项目

```bash
git clone https://github.com/berry00615/speech.git
cd speech
npm install
npm run dev
```

只使用预设题、本地评分、录音、转写和声音分析时，不需要配置服务端密钥。AI 深度反馈所需的服务商和 API Key 由使用者在应用内设置。

### 可选环境变量

在项目根目录创建 `.env.local`：

```dotenv
# 站点的公开地址，用于 Open Graph 等元数据
NEXT_PUBLIC_SITE_URL=https://example.com

# 开启“查找公开资料”和 AI 生成训练题
ENABLE_PUBLIC_RESEARCH=true
ANTHROPIC_API_KEY=your_anthropic_api_key
```

`ENABLE_PUBLIC_RESEARCH` 未设为 `true` 时，公开资料研究接口会保持关闭。请勿提交 `.env.local`；仓库已通过 `.gitignore` 排除所有 `.env*` 文件。

## 技术结构

- **界面与路由**：React 19、Next.js App Router
- **构建与运行时**：Vinext、Vite、Cloudflare 插件
- **本地语音识别**：Transformers.js、Whisper、WebGPU/WASM、Web Worker
- **本地存储**：`localStorage`（文字记录）与 IndexedDB（录音）
- **数据验证**：Zod
- **AI 服务**：Anthropic SDK、OpenAI SDK 与兼容接口
- **离线外壳**：Web App Manifest、Service Worker

核心目录：

```text
app/
├── api/                  # AI 连接测试、深度反馈与资料研究接口
├── features/
│   ├── ai-provider/      # BYOK 设置与会话内密钥管理
│   ├── audio-analysis/   # 本地声音分析
│   ├── topics/           # 题库、自定义题与研究题
│   ├── training/         # 录音、训练历史、趋势和反馈流程
│   └── transcription/    # Whisper Worker 与 WebGPU/WASM 调度
├── lib/
│   ├── domain/           # 领域规则与证据校验
│   ├── schemas/          # Zod 数据契约
│   ├── server/           # AI 服务适配与安全转发
│   ├── scoring.ts        # 可复现的本地训练量表
│   └── storage.ts        # 本地历史与录音存储
└── speech-coach.tsx      # 主训练流程
```

## 当前限制

- 本地 Whisper 模型首次下载体积较大，速度取决于网络和设备性能。
- WebGPU、浏览器实时字幕和录音格式的支持程度因浏览器而异。
- 本地量表基于可观察规则，不代表专业考试评分或事实核验。
- 声音指标会受到麦克风、环境噪声、压缩和个人声线影响，只适合同设备纵向参考。
- 训练记录目前只保存在当前浏览器，清除站点数据会同时清除记录；已有 JSON 导出，但尚未提供导入恢复。
- 公开资料研究依赖部署方启用并配置 Anthropic API。

## 未来规划

以下是方向性路线图，不是固定交付承诺。优先级会根据真实训练反馈调整。

### 第一阶段：把现有闭环做稳

- 增加 Playwright 端到端测试，覆盖录音失败、转写中断、重讲和数据清除等关键路径。
- 改善模型下载进度、缓存状态、失败恢复和低性能设备体验。
- 完成键盘操作、屏幕阅读器提示、色彩对比与移动端布局审查。
- 为训练记录、题目快照和评分版本建立更明确的数据迁移策略。

### 第二阶段：让进步更可解释

- 提供训练记录导入与恢复，形成完整的数据可携带闭环。
- 增加按题型、维度和时间范围查看的趋势分析，同时明确样本不足时的不确定性。
- 建立匿名、可复现的评分基准集，持续校准本地量表与 AI 反馈的一致性。
- 把反馈动作沉淀为短练习，让下一次训练能直接针对薄弱维度选题。

### 第三阶段：支持真实使用场景

- 增加面试回答、课堂汇报、工作提案和即兴发言等训练模板。
- 支持自定义准备时长、演说时长、评分重点和听众角色。
- 提供可选的端到端加密同步方案，同时保留完全本地模式。
- 在获得明确授权的前提下，探索多人互评、教练批注和可分享的只读训练报告。
